# [Company] marketing brain

Everything we know about selling and marketing [product], in one place. Read by people and by every AI we use.

**New here?** Start with `positioning/`, `customers/` and `experiments/channels.md`. Then ask your AI anything: it reads this repo first. If it can't answer, your question lands in `open-questions.md` for the founder.

| Folder | What's in it |
|---|---|
| customers/ | Who buys, why, the words they use |
| positioning/ | Who we're for, what we believe, competitors, this quarter's goals |
| proof/ | Numbers and case studies, each with a source |
| voice/ | The company's voice and the founder's own |
| gtm-motions/ | Every motion that brings revenue and the channels behind it |
| experiments/ | Everything we tried, including what did nothing |
| tools/ | What each tool is for and who grants access (never passwords) |
| processes/ | Recurring work, written from screen recordings |
| skills/ | The prompts and Claude skills we use |
| brand/ | Colours, fonts, logo rules, links to the files on Drive |
| digests/ | What changed, day by day |

Rules for changes: `CLAUDE.md`. Mode and people: `brain.yml`.
